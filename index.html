Log into GitHub as anilsfdc3006-ctrl (the account that owns this site).

A. In this Family Tree app

  1. Tap ☰ (top right) → Save settings (this screen).
  2. Leave repository as anilsfdc3006-ctrl/family-tree.

B. Create a GitHub token

  1. On github.com, tap your profile photo (top right) → Settings.
  2. Scroll the left menu to the bottom → Developer settings.
  3. Personal access tokens → Tokens (classic).
  4. Generate new token → Generate new token (classic). Confirm password if asked.
  5. Note: family-tree-website-save
  6. Expiration: 90 days (or No expiration if you prefer).
  7. Scopes: tick repo (the first checkbox). Leave the rest unticked.
  8. Tap Generate token. Copy the value starting with ghp_. GitHub shows it only once.
  9. Or use this shortcut (same form, repo already ticked): Open token form.

C. Publish

  1. Paste the token in the box below.
  2. Tap Publish to website. Status should say “Saved to website”.
  3. Wait about 1 minute, then open the live site on the other phone.
  4. After adding more relatives later: ☰ → Save to website.

The token is never stored in the family JSON. Only you need it — relatives can still view the published tree.
